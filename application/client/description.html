Description and documentation

About ToyOrders

ToyOrders is an application for the sales staff of our toy shops. With it they can create the orders of the customers and see the saved orders.

Operations menu

After the login you will see the operations menu. Choose an operation in the list and click "Go".

1. Create a new order

Write the order ID and the customer data (name, address, email and phone). Check the products the customer wants and write the quantity. Click "Send order" and you will see the total price with 21% VAT.

2. View orders

  • All orders: shows a table with all the saved orders.
  • One order: write the ID of an order and click "Search" to see a table with the data of that order.
